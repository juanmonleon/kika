KIKA Documentation
==================

The manual of kika as a PDF: how kika is built, how it reads and writes each format,
and the methods it computes with, with their assumptions and validation. How to use
kika (the user guide, the tutorials) and the API reference (every function's parameters
and return values, generated from the code) are part of the online documentation and
are not repeated here.
