kika.energy_grids
=================

Predefined group structures, as lists of group boundaries in MeV:
``VITAMINJ174``, ``VITAMINJ175``, ``SCALE44``, ``SCALE56``, ``SCALE238``,
``SCALE252``, ``WIMS69``, ``ECCO33``, ``ONEGROUP20``, ``CASMO12``, ``CASMO40``,
``CASMO70``, ``LANL30`` and ``XMAS172``; and a builder for an equal-lethargy grid.
