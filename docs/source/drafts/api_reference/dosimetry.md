# kika.dosimetry

Neutron spectrum adjustment with dosimeters by generalized least squares: a calculated
group spectrum with its covariance, dosimetry cross sections with theirs and measured
reaction rates with theirs give the adjusted spectrum, its covariance and the
consistency of the measurements. The linear algebra is {func}`kika.algebra.linear_update`.
